# Investment Calculator

A React investment calculator that estimates investment growth based on an initial investment, annual contributions, expected return, and duration.

## Live Demo

[View Live Demo](investment-dashboar-react-app.vercel.app)

## Features

- Calculate investment growth
- View yearly results
- GBP, USD and EUR currency options
- Input validation
- Reset calculator
- Export results as a PDF

## Built With

- React
- JavaScript
- Vite
- Tailwind CSS
- Recharts
- jsPDF

npm install
npm run dev
